# Liyuan Agent 1.5.1

## 更新

### 输出形式完全由预设主导

移除梨园残留的分段起草工具，模型直接写出正文，不再经内部脚手架中转。正文的标题、结构、状态栏与排版完全由预设与角色卡作者决定，梨园不再叠加自有的输出格式要求。

### 设定检索交回模型

设定注入由「命中即塞入结论」改为只提供检索位置，由模型按需自行查阅。设定引用更准确，脑内推演减少，正文更少丢字。关闭思考的档位下模型不会主动检索，此时自动补充被动供料兜底。

### 世界书、预设、角色卡全部工具化

世界书、预设、角色卡、用户身份与世界线全部开放给 agent 读写。扮演过程中可按需查阅设定、修改角色卡、登记新内容，不再局限于导入时的一次性注入。

### 登场名录记时间，世界状态记「在场」

世界状态记账拆为两部分：**当前状态**覆盖式更新时间、地点、人物关系、物品与剧情线；**登场名录**追加记录人物、地点、物件、剧情线的首次登场时间。名录改记登场时间后不再随剧情过期，与当前状态各司其职。新增地点与在场追踪，可区分同一场景中谁在场、谁仅被提及，离场等判断有了依据。

### 加载更快，面板不再反复读取

服务端响应全面启用 gzip 压缩，首屏体积由 668KB 降至 196KB，预设、卡片皮肤等大块响应缩小 2 至 5 倍，弱网与低配服务器下加载显著加快。已打开过的面板再次打开时直接呈现上次内容并在后台静默刷新，仅在内容变化时重新读取。

## 修复

### 角色卡打开缓慢、正文被误删

修复多处角色卡显示问题，均源于梨园对作者自带正则与标签的处理：

- **打开对话卡卡顿十余秒**：作者正则在长正文上灾难性回溯，改为字面预筛后恢复即时打开。
- **多思维链角色卡正文被整段删除**：梨园曾猜测作者的思维链标签并连同内容隐藏，误删了包裹正文的标签，此类猜名单已退役。
- **重美化角色卡滚动卡顿**：改为滚入视口后再渲染。

### 世界状态与面板编辑无法保存

修复在「世界状态」「面板」编辑窗口保存的修改不生效的问题。此前修改仅落入磁盘文件，未同步进引擎每拍读取的会话快照；现已正确写入会话，引擎每拍读到的均为最新内容。

### 会话列表打开时闪烁

修复点开「会话」面板时列表先清空、再重新载入而闪烁的问题。现直接呈现上次列表并在后台静默刷新。
