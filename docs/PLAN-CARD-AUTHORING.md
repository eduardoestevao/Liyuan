# 角色卡制作与修改：独立能力维度

2026-09-07 用户补充，已记录，尚未设计或开工。当前先完成 [回归 pi 第三刀](PI-RETURN-KNIFE3.md)。

梨园的 agent 能力至少有三个维度：扮演时推进剧情、对正文进行修订、制作和修改完整角色卡。本轮原清单覆盖前两个维度，不能据此宣布角色卡制作能力完备。

用户实际用梨园写卡时，已经能创建角色卡和世界书；缺口是复杂卡中的代码、MVU 变量及其规则、各种状态栏等内容。后续需要把角色卡作为一个含相互依赖资源的完整作品调查，不能只补文本字段或增加“创建卡/创建世界书”按钮。

后续调查至少覆盖：

- 卡内代码及关联资源的读取、定位和修改，保持原始结构与作者内容。
- MVU 变量结构、初值、更新规则与运行时结果之间的关系。
- 状态栏及其 HTML/CSS/JavaScript、模板和数据绑定。
- 跨资源修改的一致性、预览和验证，以及导入导出的完整性。

以上是待调查范围，不代表当前已逐项审计，也不在第三刀中顺手实施。具体工具设计应以真实复杂卡和现有加载/渲染机制为依据，再与用户审阅。
