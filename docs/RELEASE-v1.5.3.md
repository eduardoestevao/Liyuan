# Liyuan Agent 1.5.3

## 更新

### 悬浮窗

世界线、登场名录与 agent 自建面板移入可拖动、缩放的悬浮窗，位置与尺寸自动记忆；手机端为底部抽屉，不遮挡输入栏。左下角新增悬浮球，点击唤出各面板。agent 面板拆为两层：外观写一次，数据每拍随记账推进，不再每拍注入整页 HTML。

### 角色卡与世界书支持新建

卡库新增「新建卡」，填卡名与开场白即建，其余字段在详情里补写；世界书面板新增「新建世界书」。两者与 agent 的建卡、建书工具共用同一实现。

### 向量记忆按剧情分支隔离

重 roll 丢弃的那一拍此前仍会入库，下一次生成被召回，模型把废弃分支当作「上一拍」写成续写。现在每条记忆带上剧情树上的位置，只在该位置仍属当前分支时可见。回退、切换变体、开分支同样适用。

### 同一模型可建多条配置

条目身份由模型 id 改为条目名，同一模型可多条条目、各配思考档位，互不影响。

### 旁路模型可自定义

记账与上下文压缩可指定另一条模型条目执行，档位、耗时与思考量随过程条回执。不配置时行为与旧版一致。

## 修复

- 世界书面板常驻灯与关键词灯颜色接反，点「改为常驻」实际写入关键词触发。现按酒馆约定：蓝灯常驻，绿灯关键词。
- 登场名录的登场时间被长名字挤成竖排单字。名字与时间改为分行。
- 新建对话时界面整页刷新一次；已是全新会话时重复点击「新建」不再重建。
- agent 每轮结束清空全部面板缓存，预设等大块数据在慢速服务器上反复重载。改为只清本轮真正写过的部分。
- 卡界面页签点击失效：注入垫片时 jQuery 源码中的 `$1` 被替换模式吞掉。
- 预设自带的悬浮球与「正则未正确更新」弹窗不再出现；预设的显示正则不受影响。
- 通知气泡停留 4 秒改 2 秒；手机端气泡让开面板关闭按钮；会话面板支持多选删除；扮演教导技能增加显示开关。
