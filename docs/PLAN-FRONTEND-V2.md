# 前端大改：回到 IDE 型 agent 的形状

2026-09-09 用户定案：**大改前端**，样式回归 IDE 类 agent（参考物：CodeBuddy 手机版四张截图，本机 `E:\新建文件夹 (13)`，不进仓库）。工坊在新前端里接回（[PLAN-CARD-STUDIO.md](PLAN-CARD-STUDIO.md) 第五节），再继续功能更新。

## 一、问题定性

梨园现在有 12 个面板入口，散在**五个地方**：顶栏左 4（连接/提示词/扩展/上传）、顶栏中 3（工坊/设置/面板坞）、顶栏右 3（角色卡/世界书/用户角色）、输入框工具行 4（会话/世界线/名录/上传）、悬浮球（世界线/名录/agent 面板）、发送钮右侧（助手）。再加左右 gutter 的品牌、角色名、告警铃、连接点。

用户要记五个地方才知道东西在哪，而聊天面被这一圈按钮压得没有主角相。参考物给的答案是**三键**：左一键展开配置，右两键＝新建、会话树；标题区兼作状态；其余全部收进抽屉。

**这一刀的本质是减法，不是加壳。**

## 二、判据（比清单本身重要）

分东西只问一句：**换一个会话，它还在不在？**

- **在** → 资产 / 配置 → 进左抽屉。
- **不在** → 这一场戏的运行时状态 → 留聊天面或会话树。

按铁律四，这条判据就是「没见过的面板往哪放」的答案：以后新面板不必一事一议。

## 三、左抽屉：轨 + 面板

不用「一条折叠列」——梨园的面板体量撑不住（世界书单卡 356 条、卡库是封面网格、`PresetPanel` 896 行）。按参考物：**窄轨放图标，右边是当前板块**。

| 轨位 | 板块 | 内容 | 组件 |
|---|---|---|---|
| 顶 | 品牌 | 点＝欢迎页 | `BrandLogo` |
| 1 | **角色** | 双钮切换 `角色卡库` ⇄ `用户角色`；卡库头部带工坊入口 | `RolesPanel`（新，壳）＝ `CardPanel` + `PersonaPanel` |
| 2 | **连接** | 渠道 / 模型 / 密钥 | `ConnectPanel` |
| 3 | **提示词** | 全局系统 + 局部条目 | `PresetPanel` |
| 4 | **世界书** | 卡内书 + 独立书 | `LorebookPanel` |
| 5 | **扩展** | 技能包 / MCP / 工具开关 ＋ agent 自建面板坞 | `PowersPanel` + `PanelDock` |
| 6 | **资料** | 上传的图片与文件 | `UploadsPanel` |
| 底 | **设置** | 全局设置 | `SettingsPanel` |

轨位 1–3 是用户点名的顺序；4/5/6 由本文定：世界书紧跟提示词（同为「喂给模型的文本」），扩展再往下，资料垫底。

原打算「上传区不占轨位，只留输入框的 `＋`」——但输入框那个 `＋` 是**文件选择器**，`UploadsPanel`（浏览已传文件、重新附带）只有顶栏那一个入口，不给轨位＝静默丢功能。故补为轨位 6；输入框的 `＋` 保持原样不动。

抽屉在桌面仍是**浮在左留白上的卡片**，不挤压聊天列（沿用 2026-07-09 用户定调：面板是浮层，聊天列永远相对屏幕居中）；手机仍是顶栏之下铺满、顶栏保持可点（沿用 2026-07-26 定调）。参考物桌面版把轨钉成真列，那会改变聊天列宽度，属另一议题，本刀不做。

## 四、顶栏三键

- **左**：抽屉键（`IconPanelLeft`）
- **中**：主标题＝会话名（无则「新对话」）；副标题＝`卡名 · 扮演/写卡 · 空闲|生成中|连接中`，末尾在有告警时长出一个红点（点开＝原告警列表），无告警零占位
- **右**：新建（`IconNewChat`）、会话树（`IconSessions`）

副标题这一格是白捡的：**角色卡名**（原右 gutter）、**扮演/写卡模式**（原输入框上方模式条）、**忙闲与连接态**（原右 gutter 的 `busy`/`dot`）三样合成一行，右 gutter 整个删除。

被顶栏删掉的入口去处：品牌→抽屉轨顶；工坊→角色板块；设置→抽屉轨底；面板坞→扩展板块；告警铃→副标题红点；角色名/状态点→副标题。

## 六、按最合理读法推进的三处（用户未逐条答复，随时可一行推翻）

1. **「角色库」＝用户角色（persona）**。理由：`登场名录` 是本会话运行时状态（按第二节判据不进抽屉），与「库」的语义不符；角色卡库＋用户角色＝「AI 演谁 / 我演谁」，两钮切换成立。
2. **世界线本刀不动**，仍在输入框工具行与悬浮球；合并进会话树留到刀 3。
3. **右栏助手不动**，仍在发送钮右侧。写卡模式进主会话后它的位置变尴尬，属独立议题。

### 用户现场批评与架构纠正（图层与顶栏归位）

用户看完 CodeBuddy 桌面展开/折叠两张实测截图后直接指正：
1. **左栏与主工作区图层不对**：之前把左栏做成了 `position: absolute` 的悬浮卡片（带投影和圆角，浮在聊天流上）；CodeBuddy 在桌面端**左栏与主工作区是在同一个图层（同为 in-flow 弹性列）**，平立分栏、满高贯通（`height: 100%`），右缘 1px 细线分隔，彻底消除了“浮空面板压住内容”的压迫感与质感廉价感。
2. **顶栏在展开与折叠时是分开的**：之前顶栏横跨全屏架在整个应用上方，导致左栏头顶白白被压了一条空带，空间极度浪费。现在顶栏归属右侧 `.workspace`：
   - **展开时**：顶栏从左栏右边缘开始，与左栏并立，高度与左轨 Logo 区、面板头（`.panel-head`）完全对齐为统一的 48px 水平基线；
   - **折叠时**：左栏收起，工作区占满 100vw，顶栏横跨全屏。
3. **居中逻辑**：
   - 展开时：顶栏标题与中央聊天/欢迎区在**除去左栏后的右侧剩余空间（.workspace）**中自适应绝对水平居中；
   - 折叠时：在整个 100vw 视口中绝对水平居中。
4. **悬浮球避让与质感**：悬浮球（PanelOrb）默认位置改至右下角（`winW - 74, winH * 0.76`），不覆盖左轨与聊天流；GitHub 徽标剔除生硬纯黑，回归梨园温润暖白与朱砂微质感体系。
5. **移动端保持抽屉逻辑**：保持 `@media (max-width: 999px)` 下抽屉满屏滑出、顶栏常驻可点的窄屏体验。

### 实际做了什么

- 顶栏 4-2-4（12 入口散在五处）→ 三键。删除：`LEFT_PANELS`/`RIGHT_PANELS`/`LEFT_OPENABLE`/`CenterMenu`/中央下拉（`tb-drop*` 整段 JSX 与 CSS）/左右 gutter/品牌位/角色名/告警铃常驻位/连接点。
- `PanelId` 收敛：删 `card`、`persona`，增 `roles`；新增 `DRAWER_SECTIONS`/`DRAWER_PANELS`，`RIGHT_OPENABLE` 缩为 `sessions` + `assistant`。
- 抽屉＝`.side-left` 内加 `.drawer-rail` + `.side-main`，沿用原有保活（`leftKeep`）、刷新（`manualTick`）机制，没另起一套面板容器。
- **左栏统一定宽（彻底根除跳跃）**：移除历史遗留的 `WIDE_PANELS` 与 `side-wide`，所有 7 个板块严格定宽 `--sidebar-w: 370px`（左轨 50px + 面板 320px），切换任何板块侧栏稳如磐石。
- **主界面会话收进大框**：告别一条条散落悬浮的会话卡片，整合成一个统一的大框容器（`.welcome-recent-card`），内含分割线列表行与角标统计，区域规整清晰。
- **主界面定高、彻底砍掉下滑多余内容**：删除主页下方多余的欢迎气泡（`#0`）、说明长文提示与快捷入口按钮行；固定展示前 3 个会话，桌面与手机端均**一屏纯净呈现，纵向滚动条彻底消失（`hasScroll: false`）**。
- **世界状态大小扩展至与输入框齐平**：`.status-above`、`.status-strip`、`.status-strip-bar` 与展开后的 `.status-card` 统一使用 `width: 100%; box-sizing: border-box;`，左右边缘像素级完全对齐 `.composer-box` 输入框（实测 x=465, w=880 完全一致）。
- **左侧标题栏扁平化整合**：将 `角色卡库` ⇄ `用户角色` 分段切换直接融入 48px `.panel-head`，右侧并置 `[✎工坊] [↻] [✕]`，彻底消除“大标题 + Tab行 + 返回面包屑”的三层垂直高度浪费。
- **卡片空字段标签化**：简介/性格/场景/作者注为空时，不再渲染 4 行臃肿的空折叠条，收纳为紧凑的 `[＋简介]` 等微标签，点击即进入编辑。
- **会话历史头像修复**：修复非当前会话退化为单字占位符的问题，同卡会话统一继承卡面立绘；真无立绘时使用古典朱砂印章风。
- **现代极细滚动条**：全局滚动条换为 6px 半透明微圆角滑块，彻底告别浏览器原生粗灰槽。
- 扮演/写卡的开关从输入框上方移进副标题（带生动状态指示点），输入框少一行；会话从输入框工具行移到顶栏右键。
