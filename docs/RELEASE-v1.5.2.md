# Liyuan Agent 1.5.2

## 更新

### 兼容 MVU 角色卡

MVU 是社区广泛使用的变量插件，采用它的角色卡把人物状态、进度与物品存成一棵变量树，卡自带的界面读这棵树作画。梨园此前不认这套协议，这类卡的面板、装备页与进度页一律为空。

现在梨园自己持有这棵树：开局按卡的声明建立初始值，每拍由场记读剧情推进，树随世界线一同存档与回档。初始值的两种声明形式都支持——世界书里的初始数据条目，以及角色卡运行时脚本注册的结构默认值。

变量更新规则不再送进主模型的上下文。这份规则的读者是场记，主模型拿到它既无指令也无消费者，一张实测卡的常驻上下文因此从 8077 字降至 7329 字。

### MVU 状态栏

这类卡的状态栏并非模型写出来的：插件在回复落定后往消息末尾追加一个占位符，卡自带的显示正则再把它换成完整面板。梨园此前缺了追加占位符这一环，面板从不上屏。

现已补齐，状态栏出现在最新一条回复下。只补最新一条：梨园只持有当前一棵树，拿当前值去画历史消息即是对历史撒谎。

### 角色卡与预设的悬浮窗

角色卡与预设可以自带运行时脚本，在页面上挂一个常驻悬浮球，点开是独立面板。梨园此前不读这条通道，悬浮球不会出现。

现在这些脚本在页面级沙箱内运行，悬浮球贴在视口边缘，可拖动，位置在本机记住，随页面滚动保持不动。带 MVU 变量树的卡，悬浮球开局即显示时间、地点与在场人物。

依赖酒馆界面内部结构才能生效的脚本仍无法工作——例如靠翻找酒馆提示词管理器来开关预设条目的那类按钮，悬浮球会出现但按钮无效。

## 修复

### 角色卡界面的四处显示缺陷

- **作者样式表被当正文印在屏幕上**：整页界面里的 `<style>` 与 `<script>` 曾被剥成散文，界面塌成裸文本。现按 HTML 规范豁免非散文元素。
- **以 `<head>` 起头的整页界面不被认领**：四处「是不是界面」的判据各自为政且都漏了这一形态，现收拢为一份只问语法的判据。
- **界面页签点不动**：运行时垫片缺少一个酒馆全局函数，导致整份界面初始化中断。已按公开契约补齐读取与工具函数。
- **开场白里露出标签源码**：清理残留空标签的规则只认带空格的自闭合写法，`<foo/>` 这类被漏下并以源码形态上屏。
