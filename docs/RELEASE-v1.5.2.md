# Liyuan Agent 1.5.2

## 更新

兼容 MVU 角色卡、MVU 状态栏以及角色卡的悬浮窗。

---

## 安装包

| 平台 | 文件 |
|------|------|
| Windows | `Liyuan-1.5.2-windows.zip` |
| Linux | `Liyuan-1.5.2-linux.zip` |
| macOS | `Liyuan-1.5.2-macos.zip` |
| 校验 | `SHA256SUMS.txt` |
| **Docker** | 仓库 `docker-compose.yml`，`docker compose up -d --build` |

> 装了旧版的用户，主页会出现「新版本 v1.5.2」提示，点开即可一键升级。

## 快速开始

见各包内 `RELEASE.txt` / `start.bat` · `start.sh` · `start.command`。需要 Node.js **≥ 22**。
